天使の調伏

天使は降魔術Lv.8から調伏できるようになる敵である。通常のダンジョンに出てくることはない。

目次 (クリックでスクロール)

  • 壁から腕

基本情報

色

第一形態：薄橙
第二形態：白

見た目

大きめの丸に腕が4本生えており、第三形態になるとさらに4本増える。
天使って見た目ではない。

この腕は制作者の実写らしい。素晴らしい開発者精神だ。

攻撃パターン

なんと全56種。解説の都合上、各攻撃に番号を振った。

編集する

1. 壁から腕

説明

プレイヤーに近い位置の壁から腕が生えてくる。
生えてきた後もしばらく残っているが、一度掴まれると消える。

この腕に触れると、腕の方向に真っ直ぐ吹っ飛ばされる。
このとき飛ばされる方向に天使がいると、接触により一確というコンボをくらう。

対処法

腕の長さは限られているので、ステージの中央にいれば無論当たらない。
警告が出てから動き出しても割と避けられる。
天使から逃げているときに、ミスでぶつからないように注意すれば十分だ。

2. 波動弾

説明

手にエネルギーを溜め、大きめの球にして1~2個飛ばしてくる。
球は着弾すると爆発するオレンジのものと、途中で破裂して十字にビームを出す青の2種類がある。
どちらが出てくるかはランダム。

対処法

どちらも動き続けていれば躱せる。
青はプレイヤーの真上か真横にくると破裂してビームを出してくるので注意。
青は壁に当たると消える。

3. 全方位弾幕

説明

360度に20個のオレンジの小さめの球を4回飛ばす。
球は毎回ズレているので、隙間になる部分も毎回異なる。

対処法

球の数が多いとはいえ、隙間は大きいのでそこに入れば良い。
天使から遠いほうが隙間が大きくなり避けやすい。

4. 螺旋弾

説明

天使の手を中心に、螺旋を描くように全方位弾幕と同じ球をたくさん飛ばしてくる。
途中で螺旋の向きが逆になる。

対処法

球ごとに発射された時間が違う分、全方位弾幕より隙間が狭い(気がする)。
かなり距離をとって避けるようにしたい。

5. 薙ぎ払い

説明

ゆっくりと角度を変える太めのビームを2回撃ってくる。
1本目が終わる前に2本目を撃ち始める。

対処法

回転がそこまで速くないので動き続けていれば避けられる。
少しの移動で避けることができるので、天使に近いほうが良い。

6. 叩きつけ

説明

地団駄を踏むような動きをして、ランドルト環状のウェーブを3回飛ばしてくる。
切れ目の位置は毎回ズレている。

対処法

攻撃が始まる前から立ち止まっているだけで避けられる。
切れ目はズレるが、ギリギリ当たらない。

7. 床爆撃

説明

プレイヤーの近くに大きめの爆発を14回起こす。
警告のゲージがMAXになると爆発するので、それまでは範囲内にいても大丈夫だ。

対処法

爆発はある程度ランダムな位置に起こるので、避けれない時もある。
ひたすら円が無いところに走るしかない。

8. 追尾光球

説明

紫の大きめの球を3つ飛ばしてくる。
この球はホーミングしてきて、しばらくすると自動で爆発する。

対処法

かなり球のスピードが速いので、ステージを大回りするようにして逃げる。
十分な距離をとっていないと、最後の爆発に巻き込まれる。

9. 格子レーザー

説明

縦方向のビームを4本、横方向のビームを3本、順に飛ばしてくる。
ビームは継続時間こそ短いものの、かなり太い。

対処法

本数としては少なく間隔が大きいので、余裕をもってビームの間に入れる。
警告よりもビームが太い点には注意。

10. 回転X砲台

説明

十字状に回転しながらビームを発射する砲台を2個設置する。
1つはプレイヤーの近くに、もう1つは少し遠くに設置される。

対処法

なるべく砲台に近づいて一緒に回転する。
しかし2つの砲台は回転方向が異なるので、しばしば絶対に避けられない状況になる。
神に祈るしかない。

11. 櫛の腕

説明

左右の壁から、一定間隔で腕が5本生えてくる。
この腕は割とすぐに消える。
さらに、ステージ中央で5回爆発が起こる。

対処法

爆発はランダムな位置で起こるので、狙って避けるのは難しい。
腕の間隔がかなり広いのでその間に入るのが良いだろう。
多少壁際に追い詰められるので、腕が消えたらすぐに中央に戻りたい。

12. 弾の壁

説明

全方位弾幕と同じオレンジの球を上から下に3回、左から右に飛ばしてくる。
縦のときは左右2箇所に、横のときは中央に隙間が空いている。

対処法

隙間までの距離がかなり遠く弾速も遅くないので、始めから隙間に寄っていないとほぼ当たる。
縦の隙間は中央・右寄り・左寄りで固定なので、一発被弾を覚悟すれば残りは避けられる。

13. 突進

説明

プレイヤーに狙いを定めて、勢いよく突っ込んでくる。
触れたらもちろん即死だ。 壁にぶつかると衝撃で画面が揺れ、全方位弾幕を1回飛ばす。

対処法

横に動き続けていれば普通に躱せる。
壁が凹んだところに引っ掛けると、ほぼ無力化できる。

14. 扇撃ち

説明

全方位弾幕と同じ球8個を3回、角度をつけて飛ばしてくる。
始めは広角だが、だんだんと真っ直ぐに球を集中させて飛ばしてくる。
このとき、球を飛ばしてくる向きは1回目から変わらない。

対処法

球は腕から真っ直ぐにしか飛ばせないので、腕の中にいると簡単に避けられる。

15. 瞬間移動散弾

説明

ランダムな壁際にワープして全方位弾幕と同じ球を9個投げるのを3回繰り返す。
かなり離れた位置にワープし、球も広角である。

対処法

球がバラけているので、隙間も大きくかなり避けやすい。

▲目次へ戻る

16. 殴り飛ばし

右に大きく飛ばされ、弾幕がはじまる。
球は全方位弾幕と同じ。 左の壁から十分に離れていないと、発生しない。

対処法

かなり右端でないと避けるのに十分な隙間がない。
そのため右手が邪魔になり、物理的に攻撃がしずらい。
一発あたる覚悟で突っ込めば、左端は安置だ。
第一形態の開幕ルーティンに含まれているが、ステージの左端にいればキャンセルできる。

17. 反射弾

説明

壁にあたると跳ね返る緑の大きめの球を12個出す。
4回壁にあたって跳ね返るか、一定時間が経過するまで消えない。

対処法

弾速は遅めで壁にあたるときれいに反射するので、軌道の予測は簡単。
それでもなるべく広い所で避けるようにしたい。

18. 足跡の爆弾

説明

プレイヤーが立っている所を中心に爆発を9回起こす。
常にプレイヤーの場所を中心に爆弾を設置するので振り切ることは出来ない。

対処法

爆発までに十分な時間があるので、折り返さずに動き続けていれば全て避けられる。

19. 重力

強い力で天使を中心に引っ張ってくる。
引っ張っている最中に全方位弾幕と同じ球を少しずつ飛ばしてくる。
吸引が終わると、さらに全方位に球を飛ばしてくる。

対処法

天使と逆に動き続けていれば耐えられるようになっている。
終了時の球はかなり速く数も多いので、吸引が終わっても距離をとるようにしたい。

▲目次へ戻る
編集する

20. 狙撃

薙ぎ払いと同じビームを4回撃ってくる。
薙ぎ払いとは違い、常にプレイヤーを狙い続けてくる。
また、予備動作と1本あたりの効果時間が短い。

対処法

狙い続けてくるといっても撃つ直前には固定されるので、動き続けていれば良い。
ただし、毎回ビームの中心が変わるので動き方も少し変える必要がある。
